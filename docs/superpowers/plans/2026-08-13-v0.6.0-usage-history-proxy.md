# Codex SwitchBridge 0.6.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship 0.6.0 with reliable proxied quota queries, automatic legacy-cache cleanup, and a bilingual daily/weekly/monthly local-token history dashboard.

**Architecture:** Pass a sanitized explicit proxy through the existing quota-query context instead of mutating process environment. Derive UTC daily usage buckets from the existing v2 increment index, project only secret-free values into the dashboard model, and aggregate/filter those buckets locally in the Webview.

**Tech Stack:** TypeScript 5.9, Node HTTPS and `https-proxy-agent`, VS Code Extension API, esbuild, Node test runner, DOM/CSS, Playwright, npm workspaces, GitHub CLI, `@vscode/vsce`.
